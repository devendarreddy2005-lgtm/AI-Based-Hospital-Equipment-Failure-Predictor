# AI-Based Hospital Equipment Failure Predictor

## Project Description

This project is an AI-powered hospital equipment monitoring and failure prediction system developed using Python, Streamlit, Machine Learning, and Data Analytics.

The system predicts equipment failures, identifies high-risk machines, generates maintenance alerts, monitors equipment health, and provides financial analytics to help hospitals reduce downtime and maintenance costs.

## Features

### Live Dashboard
- Total Machines
- High Risk Machines
- Monthly Savings
- Annual Savings

### AI Failure Prediction
- Predicts equipment failure types
- Calculates failure probability
- Identifies high-risk equipment

### Equipment Monitoring
- Real-time equipment status monitoring
- Usage limit tracking

### Financial Analytics

## Dataset Information

This project uses a simulated hospital equipment dataset created for educational and demonstration purposes. The dataset mimics real-world equipment maintenance and failure patterns while containing no actual patient or hospital data.

## Dataset Fields

- Equipment ID
- Equipment Name
- Department
- Manufacturer
- Installation Date
- Last Service Date
- Next Maintenance Date
- Daily Usage Limit
- Temperature Readings
- Pressure Load Readings
- Rotational Speed
- Power Voltage Usage
- Usage Hours Per Day
- Vibration Torque Level
- Failure Type
- Failure Probability

---

## Machine Learning Model

XGBoost Classifier is used to predict:

- Failure Type
- Failure Probability
- Maintenance Actions
